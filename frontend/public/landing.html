TogetherList supports the Model Context Protocol (MCP), so a compatible AI client can work on the same shared list as your group.

From meal plan to shared groceries

  1. Ask your connected agent to create a grocery list with Alex and Sam as participants, then add ingredients and quantities in item descriptions.
  2. Open the returned list ID at /list/{listId} and share that link with your group. People can review the plan and change assignments in the browser.
  3. As people shop and check off items, ask the agent to read the list again before suggesting changes. Agent writes change the shared list directly.

Available tools: create_list, get_list, rename_list, add_item, complete_item (complete or reopen), assign_item, update_item_title and update_item_description. Read a known list as the resource list://{listId}. There is no global list enumeration.

Connect a compatible MCP client

Choose legacy HTTP/SSE transport and use https://togetherlist.eu/api/v1/mcp/sse. Keep the SSE connection open and POST messages to the session endpoint it advertises. No API key is required.

For custom integrations, POST JSON-RPC 2.0 to https://togetherlist.eu/api/v1/mcp with Content-Type: application/json. This direct POST endpoint is not Streamable HTTP. Clients that only support Streamable HTTP cannot connect using that transport.

Anyone holding a list link or ID can read and modify that list. Display names are not authentication. Share list access only with people and agents you trust; avoid sensitive information.

Frequently Asked Questions

How do I create a shared list?

Choose Create New List, name it and add participants. Share the resulting link so others can open the list and choose their display name.

Who can access my list?

Anyone holding a list link or ID can read and modify that list. Display names are not authentication. Share list access only with people and agents you trust; avoid sensitive information.

Can I assign items to people?

Yes. Add participants by name and assign an item to one or more people. Everyone with access can change assignments.

Does it work on mobile?

Yes. Use a modern browser on your phone, tablet or computer. No app download is required.

Is TogetherList free?

Yes. You can create and share lists for free without an account.

Can an AI agent edit the same list as people?

Yes. Connect a compatible MCP client using legacy HTTP/SSE. An agent can create and read lists, rename lists and items, add and describe items, assign them, and mark them complete or incomplete.

Which MCP transport should I use?

Choose legacy HTTP/SSE transport and use https://togetherlist.eu/api/v1/mcp/sse. Keep the SSE connection open and POST messages to the session endpoint it advertises. No API key is required. For custom integrations, POST JSON-RPC 2.0 to https://togetherlist.eu/api/v1/mcp with Content-Type: application/json. This direct POST endpoint is not Streamable HTTP. Clients that only support Streamable HTTP cannot connect using that transport.

Can an agent discover all lists?

No. There is no global list enumeration. To read or modify an existing list, supply its ID. The list://{listId} resource also requires a known list ID.
